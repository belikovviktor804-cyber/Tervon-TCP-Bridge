## Ограничения эксплуатации

- Использовать GitHub API для файлов и документации; Git clone/pull/push — только `git@github.com:tervon-software/Tervon-TCP-Bridge.git` по SSH.
- На Homeserver и Finserver работающие Bridge, Stats, nginx, x-ui и прочие службы **не изменять** без отдельного утверждённого шага; исходники/секреты из приватных хостов не публиковать.
- Не внедрять новый UDP/QUIC scope, не менять ядро TervonVPN Android или APK в M5.
- M6 не вести параллельно: он остаётся только темой будущего обсуждения; окончательная архитектура не утверждена.
