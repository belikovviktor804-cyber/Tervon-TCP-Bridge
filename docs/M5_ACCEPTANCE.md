## Обязательное ограничение

Оператор запретил возврат к старым версиям и сравнительные испытания с ними. Ни источник предыдущей версии, ни её бинарник не требуются для принятия M5. Исторические сведения в старых логах не задают новых задач. Не разворачивать прежние сборки; не заменять и не перезапускать работающий M4 на серверах. Подготовленный ранее `tests/m5/run-m5-1-source-batch.sh` **не запускать**: он был предложен в ошибочной концепции отдельной пересборки и в текущем плане отменён. Рабочая ветка M5 может использовать существующий код и результаты тестов М4 без заново проводимых проверок.

## M5.1 — основание закрытия

- Оператор подтвердил работающий M4 на двух узлах и факт, что M4 **является v1.0.1**.
- Сохранено доказательство процесса/бинарника M4 на Homeserver и Finserver: SHA256 `5035217a89476117894efe1a44db5dcdd1242773d7fd9461170f2cf6ccb98a90`; исходный M4 candidate commit `8d0aa3777c209d2825a1c11dfbae9487893cb7f5`; M4 закрыт коммитом `eb4fde88d6477defb58f8237fd0526c292e93cfe`.
- Описаны границы и тракт VPN TCP, ранее подтверждена работа VPN/Stats; указаны недоказанные количественные параметры для M5.3.
- Предыдущие проверки происхождения исторических артефактов в GitHub **не повторяем**; теперь они не являются предусловием, метрикой или причиной для сравнения.
- **Решение оператора отменяет обязательность старой сравнительной методики.** Порогов регрессии относительно прежних версий в M5 нет. Требования к абсолютным задержкам Jitter и корректности TCP остаются обязательными.
